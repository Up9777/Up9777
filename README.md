## 🧠 About Me

> *"Good backend code is invisible — it just works, scales, and never breaks."*

I'm a **Backend Developer** with hands-on experience building production-grade systems using **NestJS**, **Node.js**, **MongoDB**, and **React**. I specialize in crafting clean REST APIs, designing scalable architectures, and turning complex requirements into robust, maintainable code.

- 🔭 Currently working on **event management systems** and **API-first applications**
- 🛠️ Strong believer in **SOLID principles**, **clean architecture**, and **test-driven development**
- 🌐 Comfortable across the stack — from database schema design to React frontends
- ⚡ Always exploring: system design, microservices, and developer tooling
- 📍 Based in **Kolhapur, Maharashtra, India**
